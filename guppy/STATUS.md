# Status

The repo has its folder structure, Obsidian-compatible notes, templates and Bases views. Events (`eventos/`) and talks (`ponencias/`) live at the root, and `wordpress/` holds the WordPress.org teams and the local communities (31 notes, one per meetup group or WordCamp community such as WordCamp Europe). The event note is the hub: talks and galleries link to it, and the event carries the web post (`articulo`, `imagen_destacada`, `revisada`) and its `comunidad`. Events have four categories (WordCamp, Evento WordPress, Meetup, Evento externo); talks without an event link straight to their community. Galleries are minimal notes for external albums (official and own), several per event allowed. The 94 events and 45 talks are reviewed; Nilo fills in the remaining data himself, and what is left is listed in `vistas/revision-ponencias-eventos.md`. The content direction is set: tell the story behind each project, talk and photo session, publishing content first and redesigning the web afterwards. The GitHub profile README is published. The project runs in short sprints. Talk posts on the web are being prepared newest first: WordCamp Portugal 2026, Galicia 2025, Google Analytics and Local by Flywheel are published; WordCamp Valencia 2026 waits for its recording. Social sharing is the last publishing step: Claude schedules each post in Buffer (Bluesky, LinkedIn, X; free plan, 10 scheduled posts per channel), see `elementos.md`; old talks are kept as a reserve for gaps in the queue. Next: write the event posts of the photo section (`/foto-video/`), newest first, and a custom template for that category. Background on the direction is in Claude's local memory on Marcianito, not in the repo.
