Desde siempre, WooCommerce se ha vendido como «el plugin para hacer tiendas online», pero la realidad es que se puede utilizar para muchísimo más. Sitios de membresía, academias online, sitios de descargas, tiendas de dropshipping, catálogos online.

En esta charla vamos a ver parte del potencial de WooCommerce y de otros plugins de comercio electrónico para WordPress para que puedas decidir qué plataforma usar a la hora de hacer tu web.
