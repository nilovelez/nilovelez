# Bio

Una bio general, completa, que es la referencia, y versiones preparadas por uso que se derivan de ella:

- `bio-general`: con todo.
- `bio-charlas`: para organizadores de eventos.
- `bio-redes`: para perfiles de redes sociales.
- `bio-profesional`: para LinkedIn y similares.
- `bio-wordpress-org`: para el perfil de WordPress.org.

Si cambia la general, hay que revisar las derivadas.
