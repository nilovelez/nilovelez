# WordPress

Lo que es de WordPress y no es un evento ni una ponencia: los equipos de WordPress.org con los que colabora Nilo y las comunidades locales (grupos de meetup) que organizan eventos.

- [`equipos/`](equipos/README.md): un documento por equipo de WordPress.org.
- [`comunidades/`](comunidades/README.md): un documento por comunidad local de WordPress (grupo de meetup).
